## ✅ Creating New SCSS Module

**🔴 CRITICAL:** Every `.module.scss` file MUST start with:

```scss
@import '@/styles/tokens.scss';
```

**Common Mistakes:**

- ❌ Using `@use` instead of `@import`
- ❌ Forgetting `.scss` extension
- ❌ Using wrong variable names (see below)

---

## 📝 SCSS Variable Names (From `styles/tokens.scss`)

### ❌ THESE DON'T EXIST:

- `$font-size-md` → Use `$font-size-base` instead
- `$line-height-normal` → Use `$line-height-base` instead

### ✅ CORRECT VARIABLES:

**Typography:**

- `$font-size-xs`, `$font-size-sm`, `$font-size-base`, `$font-size-lg`, `$font-size-xl`

**Line Heights:**

- `$line-height-tight`, `$line-height-base`, `$line-height-relaxed`

**Font Weights:**

- `$font-weight-regular`, `$font-weight-medium`, `$font-weight-semibold`, `$font-weight-bold`

**Spacing:**

- `$spacing-xs`, `$spacing-sm`, `$spacing-md`, `$spacing-lg`, `$spacing-xl`, `$spacing-xxl`

**Colors:**

- `$color-primary`, `$color-error`, `$color-success`, `$color-warning`

## 🚀 Validation Workflow

**⚠️ MANDATORY:** After every significant change or before finishing a task, you MUST run:

```bash
yarn ci
```

This runs, in order:

1.  `check:env`, `check:langs`, `check:reserved-slugs` — the environment and cross-repo guards
2.  `lint` — `eslint .` over the whole tree, `import/order` and `consistent-type-imports` at error level
3.  `typecheck` — `tsc --noEmit`
4.  `test:coverage` — vitest with the coverage thresholds

`yarn validate` was removed on 26.08.2026 (`LEGACY-155`): it took its exit code from typecheck
alone, so a failing lint was printed and lost, and the script reported success unconditionally.

**If it fails:** You MUST fix the errors before reporting the task as done.

---

yarn typecheck  # Must pass ✅
