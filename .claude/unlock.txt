# Разовые разрешения на запись.
#
# Одна строка - один путь от корня репозитория или маска (например: configs/*.yml).
# Пока строка здесь, хук защиты файлов пропускает запись по этому пути.
#
# Как пользоваться:
#   1. хук запретил правку и назвал файл;
#   2. если правка действительно нужна - человек добавляет сюда ровно этот путь;
#   3. правка делается;
#   4. строка убирается.
#
# Строки живут до конца текущей задачи, не дольше. Забытая строка - это снятая защита,
# о которой все забыли, поэтому чистить файл надо в тот же день, а не «когда-нибудь».
# Пустой файл - нормальное состояние.
#
# Строки, начинающиеся с #, и пустые строки не читаются.
